# 稳定币风险事件库

本数据集整理与稳定币自身机制、市场运行或外部使用直接相关的108起风险事件，用于研究风险起点、风险性质与传播过程。事件检索截至 **2026年9月6日**。

## 文件与使用

|文件|内容|
|-|-|
|[完整事件库](data/稳定币事件库.xlsx)|“108案详情”保留事件过程与编码字段；“来源”列出事件依据和资产证明；“统计概览”汇总分类结果。|
|[双栏事件表](data/108起稳定币安全事件.xlsx)|108案的紧凑阅读视图，附来源和分类说明。|
|[Markdown事件清单](data/稳定币事件库.md)|可直接浏览的事件清单、来源链接与汇总。|
|[案例说明](CASE_NOTES.md)|代表性案例的观察窗口、证据边界与事实说明。|

三份数据文件使用相同的读者序号。**序号是本发布包关联事件的稳定标识**，不等同于工作表行号；引用某案时，请同时注明数据版本和序号。事件文字链接至事件依据，稳定币文字链接至资产证明。资产证明用于识别资产；来源没有明确链或资产版本时，证明链接不表示事件发生链已获确认。

数据库包含核心机制51案、市场运行10案、外部生态47案；按风险性质分别为继承31案、重塑53案、特有24案。

## 字段说明

完整事件库的“108案详情”含以下字段。

|字段|含义|
|-|-|
|序号|三份数据文件共同使用的事件标识。|
|事件时间|来源所报告的发生、行为区间、公告或披露时间，保留原有精度。|
|事件名称|用于识别该次事件的名称。|
|稳定币/资产版本|相关稳定币及来源可辨认的资产版本。|
|链/主要场景|事件所在链、市场、机构或使用场景。|
|价值支撑方式|储备、抵押、算法或对冲等机制背景。|
|稳定币角色|稳定币在事件中的用途或受影响方式。|
|风险起点|首个关键风险条件对应的分类编码。|
|风险空间|核心机制、市场运行或外部生态。|
|风险类型|风险起点对应的中文类别名称。|
|风险性质|继承风险、重塑风险或稳定币特有风险。|
|首个关键风险条件|依据事件时间顺序与机制证据识别的起点。|
|事件过程|主要条件、行为与后续结果的概括。|
|价格偏离情况|“是”“否”“局部/短时”或“不适用”，保留不同价格表现口径。|
|市场表现|价格、流动性、铸赎或平台业务等可观察变化。|
|影响规模|来源报告的金额、数量或其他量化影响，依原指标解释。|
|处置结果|修复、赎回、清算、冻结、退出或其他已报告处置。|
|传播空间序列|事件后续涉及的分析空间顺序，C、M、E分别表示三个空间。|
|证据限定|来源或事实解释的特定边界；空白不表示已完成全部因果验证。|
|事件依据|支持事件事实的来源链接。|
|资产证明|支持资产身份或版本识别的来源链接。|

“来源”表中的“补充来源”和“资产证明说明”分别用于补充证据及说明链接角色。损失、交易金额、被冻结金额、罚款和赎回金额含义不同，不能直接相加为事件总损失。

## 分类规则

风险起点按事件演化向前追溯，每起事件记录一个主要起点。后续脱锚、挤兑、清算或外部损失单独记录为过程或传播结果。三个空间表示分析边界，不表示严重程度或固定传播方向。

|分析空间|边界与类别编码|
|-|-|
|核心机制（C）|稳定币自身的价值支撑或链上执行首先异常。C\_VS：价值支撑；C\_PR：协议规则；C\_CI：合约实现；C\_RD：运行依赖。发行储备与面值兑付托管，以及自身协议的关键执行依赖属于该空间；向独立生息协议配置资产属于外部集成。|
|市场运行（M）|核心机制未首先异常时，形成或恢复目标价格的市场条件发生变化。M\_LI：流动性；M\_PR：锚定修复；M\_CR：信心挤兑。|
|外部生态（E）|使用、集成、监管或滥用稳定币的外部系统、机构或行为主体首先产生风险。E\_IN：外部集成；E\_IU：违法利用；E\_RJ：监管法域。|

风险性质以一般区块链和加密资产系统为比较基线，与风险起点分别编码：

* **继承风险**：去掉稳定价值目标后，风险机制不变。
* **重塑风险**：风险来源仍然存在，但稳定目标或稳定机制改变了触发条件、传播方式或影响范围。
* **稳定币特有风险**：风险直接来自维持稳定价值而增加的资产支撑、兑付承诺、铸赎或稳定机制。“特有”限定于上述比较基线。

## 证据与解释

事件时间、行为、价格及金额等事实通过所列来源核查；风险起点、风险性质和传播空间属于作者依据事实作出的人工编码。时间先后为归因提供线索，但本身不构成因果识别。案例说明中的窗口限定与待复核编码（包括第103案）应与相应记录共同阅读。

本库基于公开可核查材料收录事件。分类数量反映该样本的分布，不代表稳定币总体风险发生率。检索截止日与事件发生日、公告日及处置计划日期分别记录；截止日前披露的后续计划不等同于已经发生的结果。
